# Daily CEO Update

**Mode:** Morning (what I'm doing today) or EOD (what happened today)
**Send via:** Slack, after review

## Format

```
* [Project Name]
   * `[One-line status or intention]`
   * `[Second line only if needed]`
```

## Standing projects (include only if active today)

```
* INSIDEA DM Operations
   * ``
* Marsin
   * ``
* Ancil AI
   * ``
* Sales Transformation 2026
   * ``
* Ambika Training
   * ``
* Other
   * ``
```

## Rules

- High-level and strategic only. No task-level noise.
- Flag blockers and decisions, not just activity.
- Escalate to the CEO rarely, and only what is strategic.
- Name the owner when work is delegated.
- Reference yesterday's progress; do not repeat yesterday's question.
- No progress is fine to say: `No heavy progress. Taking this up tomorrow.`
- First person, direct. If it can be said in 8 words, don't use 20.
- No em dashes, no emojis. Links inline.
