# Skill Index

Claude skills that pair with this playbook. Ask for the task in plain words; the matching skill loads on its own.

| Need | Say something like | Skill |
|---|---|---|
| Brand check on anything INSIDEA | "Check this against brand" | `insidea-brand-manager` |
| CEO update | "Let's do my morning update" | `daily-ceo-update` |
| New SOP | "Create an SOP for client offboarding" | `insidea-sop` |
| Policy or SOC 2 text | "Format this for the policy doc" | `insidea-policy-doc-format` |
| Client brief | "Brief on [client] for leadership" | `client-implementation-brief-generator` |
| Deck or proposal | "Build a deck on [topic]" | `insidea-reference-deck` |
| Competitor comparison | "Battle card vs [agency]" | `insidea-competitor-battlecard` |
| Status report | "Weekly ops status" | `operations:status-report` |
| Change request | "Change request for [change]" | `operations:change-request` |
| Capacity planning | "Are we overallocated next quarter?" | `operations:capacity-plan` |
| Risk register | "What could go wrong with [project]?" | `operations:risk-assessment` |
| Vendor decision | "Review [vendor] renewal" | `operations:vendor-review` |
| Process fix | "This handoff is too slow" | `operations:process-optimization` |
| Runbook | "Runbook for [procedure]" | `operations:runbook` |
| Compliance | "SOC 2 audit prep" | `operations:compliance-tracking` |
| Tough call | "Should I do X or Y?" | `decision-framer` |
