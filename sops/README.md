## How to create an SOP

1. Ask Claude: "Create an SOP for [process]." The `insidea-sop` skill runs a short interview (identity, teams, steps, references) and confirms before building.
2. Output goes to Google Docs in the INSIDEA format. Keep a Markdown copy here from `_template-sop.md` if you want version history in Git.
3. Add a row to the register above.
4. Revisions bump the version (v0.1, v0.2, v1.0 at sign-off) and get a line in the commit message.
